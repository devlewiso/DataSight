> AI-Powered Data Analysis & Visualization Platform - Now with Intelligent Chat Assistant

## ✨ What's New in v2

- **🤖 AI Chat Assistant**: Ask questions about your data using GPT-4
- **🔑 Your Own API Key**: Complete control with your personal OpenAI API key
- **🔒 Auto-Delete Security**: API keys automatically deleted on page close
- **📊 Enhanced Analytics**: More powerful data insights and visualizations
- **⚡ Performance Improvements**: Faster processing and better UX

## 🎯 Features

### Core Features
- **Multiple File Formats**: Support for CSV, XLS, and XLSX files
- **Advanced Analytics**: Statistical analysis, distributions, and outliers
- **Interactive Tables**: Clean, responsive data viewing
- **Smart Detection**: Automatic data type and format detection
- **Secure Processing**: All processing happens in your browser
- **Lightning Fast**: Instant analysis results

### v2 Exclusive Features
- **AI-Powered Insights**: Chat with your data using natural language
- **Privacy-First**: Your API key never leaves your browser
- **Zero Setup**: No sign-up, no credit card required
- **Unlimited Usage**: Analyze as much data as you want

## 🚀 Quick Start

1. Visit [DataSight](https://datasight.app)
2. Upload your CSV or Excel file
3. Get instant insights
4. (Optional) Add your OpenAI API key for AI chat features

## 💡 How It Works

1. **Upload**: Drag and drop your data file
2. **Analyze**: Get instant statistical insights
3. **Chat**: Ask questions about your data (with API key)
4. **Export**: Download your analysis results

## 🔐 Privacy & Security

- ✅ All data processing happens in your browser
- ✅ Your data never leaves your device
- ✅ API keys stored locally only
- ✅ Automatic cleanup on page close
- ✅ No server-side data storage

## 🛠️ Tech Stack

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **AI**: OpenAI GPT-4
- **Build Tool**: Vite
- **Data Processing**: PapaParse, XLSX
